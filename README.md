# lab-website

Astro source for [carpentershenlab.org](https://carpentershenlab.org).

Part of the [Carpenter-Shen Lab](https://github.com/carpenter-shen-lab) at Purdue University.

## Development

```bash
npm install        # Install dependencies
npm run dev        # Local dev server at localhost:4321/
npm run build      # Production build to dist/
npm run preview    # Preview production build
```
